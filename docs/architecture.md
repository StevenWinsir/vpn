# 控制平面与代理数据平面

## 当前结构

浏览器 Next.js/Mantine → 当前前端来源 `/api/v1/*` → Next.js Node 动态代理 → Go/Gin API → PostgreSQL。业务、鉴权和购买判断全部在 Go 完成，Next.js 不访问数据库，也不保存代理密码。数据库独立 schema 减少与已有业务的碰撞。

Next.js 服务端运行时读取 `API_INTERNAL_URL`，默认 `http://127.0.0.1:8080/api/v1`；此地址不进入浏览器配置。浏览器固定使用同源相对路径，`/api/runtime-config` 仅提供该固定路径与超时。后端公网域名可通过独立的反向代理入口继续访问，不改变网站走同机回环的链路。两者的 Cookie 按各自访问域名保存，不会自动跨域共享。

代理仅覆盖 `/api/v1/*`，请求体上限与 Go 一致为 8192 字节；保留 Origin、Cookie、Authorization、Idempotency-Key 和独立 Set-Cookie，禁用缓存及上游重定向跟随，拒绝路径穿越。不替换可信来源、不绕过 Go 的 CSRF/CORS，不转发客户端自行提供的 Host/Forwarded 头。部署仍需正确填写后端的前端来源白名单，代理下的 IP 限流聚合问题见下文。

当前 `/client/bootstrap` 只是受限元数据接口，不是订阅 YAML 下载地址。由于没有部署代理节点，接口明确报告 `proxy_service_ready=false`，不能据此展示客户端“连接成功”。

## 为什么不能仅靠隐藏 YAML

本地设备必须以某种形式持有建立代理连接所需的信息。隐藏入口、打包混淆或在客户端解密，只是降低普通用户的直接可见性，不能对控制本机的用户保证配置不可提取。不要承诺绝对隐藏 server/port/password。

共享的 Shadowsocks 密码无法可靠绑定到单个网站用户。只让后端停止返回配置，也不能让已经缓存密码的客户端自动失去节点访问能力。用户提供的样例节点和共享密码未写入本项目。

## 下一阶段建议的接口和职责（尚未实现）

1. 原生客户端向认证 API 登录，使用短期 access token 和设备绑定的 refresh token。系统钥匙串/Keystore 保存刷新凭据，不保存明文密码。设备登记、设备上限、会话撤销和风控由服务端执行。
2. 控制平面校验账号、订单来源、有效期、配额和设备，再向代理节点配置每用户/每设备可撤销的访问凭据。具体协议取决于最终选用的代理服务端是否支持多用户身份、独立撤销与可归因计量；不能假设任意共享 SS 节点都支持。
3. 管理员配置线路类型、节点标签、倍率和套餐权限；代理凭据独立加密保存，管理员操作进审计日志。公开 DTO 只返回地区、名称和状态等元数据。
4. 配置版本递增；启动时同步之外，增加运行期轮询或推送。管理后台修改后，控制平面和节点状态确认成功才显示已生效；配置缓存设置短 TTL 和显式撤销机制。
5. **节点侧**记录上传/下载计数，通过 mTLS 或专用签名通道发送带节点身份、用户身份、序列号、时间窗口和幂等键的计量批次。公开客户端只能上报诊断，不能作为扣费依据。
6. 服务端验证来源、防重放、单调计数与异常速率，按发生时的倍率快照生成不可变流量账本。使用整数单位，防溢出，保留原始字节与折算单位。计费更正使用补偿分录，而不是修改既有账本。
7. 到期/耗尽通过节点侧 ACL、凭据撤销、短 TTL 授权和连接中断执行；API 拒绝下发只是第二道防线。必须定义节点离线时的策略、额度同步窗口及最大可超用量。
8. 真实支付使用待支付订单、可信渠道回调验签、回调幂等、金额/币种/商户核对、事务激活与补单对账。浏览器支付成功跳转绝不是开通依据。测试订单永久标记为测试来源，禁止进入真实权益。

## 生产化尚缺的安全措施

当前 IP 限流存在单进程内存中；多副本需要共享限流与可信反向代理配置。当前未信任任何代理转发头，不要直接配置“信任全部代理”。

当前刷新令牌按数据库哈希原子轮换，网页标签页内合并刷新请求；尚未实现跨标签页协调、刷新令牌族的重放侦测与历史令牌撤销策略。正式原生协议应补全设备绑定、异常重复使用检测和密钥轮换方案。Cookie 部署应保持同站 HTTPS，跨站部署需重新设计 CSRF/SameSite 策略。

补齐邮箱验证、密码找回和密码修改后的会话撤销；管理员独立 RBAC/MFA；CSP/反向代理 TLS/HSTS；安全日志与可观察性；数据库最小权限、加密备份、恢复演练；版本化迁移和回滚；支付与流量账单对账；合规政策、用户协议、退款政策和开源许可审查。

本次只提供注册/登录/测试购买的可验证基础，不宣称完成上述生产运营能力。
